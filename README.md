# My Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Structure

```
My-Portfolio/
├── index.html
├── style.css
├── script.js
└── images/
    └── profile.jpeg   <- put your photo here
```

## Run locally

Open `index.html` in any browser. No build step needed.
